# OpenLection

Курсовой проект по дисциплине «Деректер базасы және SQL сұратымдар».
Тема: проектирование базы данных открытых занятий кафедры «Жасанды интеллект технологиялары»
и разработка простой веб‑системы для хранения и просмотра этих данных.

## Цель и смысл проекта
Создать и проверить на практике базу данных для открытых занятий кафедры ЖИТ,
чтобы удобно хранить, анализировать и управлять сведениями об учебных занятиях
(тема, группа, предмет, преподаватель, аудитория, дата, специализация).
Проект демонстрирует применение SQL и Django ORM в задаче управления
образовательными данными и организации открытых лекций.

## Что внутри
- Django 3.2.12, база данных SQLite (`db.sqlite3`).
- Приложение `lections`: модели специализаций и лекций, список лекций.
- Приложение `users`: регистрация, вход, профиль, кастомная модель пользователя.
- Статика и изображения для лекций/профилей.

## Запуск локально
Перейдите в папку проекта с `manage.py`:

```
cd openslection
```

1) Создайте виртуальное окружение и установите зависимости:
```
python -m venv venv
venv\Scripts\activate
pip install Django==3.2.12 Pillow
```

2) Примените миграции:
```
python manage.py migrate
```

3) (Опционально) Загрузите тестовые данные:
```
python manage.py loaddata lections/fixtures/specialization.json
python manage.py loaddata lections/fixtures/lesson.json
```

4) Запустите сервер:
```
python manage.py runserver
```

Откройте в браузере: `http://127.0.0.1:8000/`

## Полезно знать
- Админка: `http://127.0.0.1:8000/admin/`  
  Для доступа создайте суперпользователя:
  ```
  python manage.py createsuperuser
  ```
- Страницы пользователей: `/users/login/`, `/users/registration/`, `/users/profile/`.
- Страница лекций: `/lections/`.
